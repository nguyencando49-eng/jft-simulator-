## Root causes, ranked by impact

1. Planning/task construction: 2,030 mass-template records were produced from fixed quotas rather than task-specific blueprints.

3. Distractor design: 2,031 failure records.
4. Repeated generator pattern / duplicate risk: 2,030 failure records.
5. Category targeting: 1,099 failure records.
6. Level targeting: 743 failure records.
7. Listening verification/script pipeline: 513 failure records.
8. Japanese naturalness: 55 failure records.

Exact aggregates and the stratified 100-item root-cause sample are in `data/analysis/generator-failure-summary.json` and `docs/content/GENERATOR_FAILURE_ANALYSIS.md`.

## Generator changes

- Added immutable `JFT_ITEM_BLUEPRINT_V1` and explicit A1/A2.1/A2.2 generation contracts.
- Metadata now comes from the blueprint; provider output cannot change level, section, category, Can-do, topic or answer contract.
- Split core stimulus/question/answer generation from distractor generation.
- Added answer-first evidence keys and Listening dependency checks.
- Added deterministic `JFT_GENERATOR_PREFLIGHT_V1` and maximum three-attempt retry.
- Integrated blueprint generation into the existing QuestionPlan -> Factory bridge.
- Preserved QA1-QA7 and their hard-fail authority.
- Added a provider-neutral staged interface, deterministic test/pilot adapter and Azure staged adapter.

## Failure examples and architectural fixes

| Historical pattern | Why it failed | Architectural fix |
|---|---|---|
| Curriculum anchor rotated through a generic “related word” prompt | The task did not measure the declared Can-do/category | Blueprint fixes the learner operation and category before surface generation |
| Conversation used one helpful response plus unrelated weather/food/train choices | Distractors were nonsense outside the response decision space | Separate distractor contract requires the same response type and named misconception |
| Listening/Reading templates changed only names, dates and numbers | Same decision and answer pattern produced systemic near-duplicates | Per-item task/fact blueprint plus QA7 batch/bank comparison |
| Level copied from the lesson loop | Language and processing load were unaffected by level | Central level contract constrains length, facts, reasoning and distractor similarity |
