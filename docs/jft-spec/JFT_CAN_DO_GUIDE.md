# JFT Can-do guide

## OFFICIAL JFT FACT

JFT-Basic assesses practical communication based on A1–A2 Can-do statements. See the Japan Foundation sources in `JFT_OFFICIAL_SPEC.md`.

## SIMULATOR DESIGN DECISION

Each approved KnowledgeUnit and generated question records one primary Can-do. Level review considers task complexity, language, information density, inference, processing load, distractors, and situation—not vocabulary alone.
