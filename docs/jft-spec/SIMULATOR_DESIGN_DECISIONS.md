# Simulator design decisions

Everything in this file is an internal product rule, not an official JFT fact.

## Content taxonomy and topics

Use the four official sections and categories at the top level. Internally, each item should also carry a practical situation/topic, Can-do, target level (`A1`, `A2.1`, `A2.2`), language focus, provenance, and review status.

Prefer everyday situations such as introductions, home, work, shopping, food, transport, public services, health, appointments, rules, emergencies, and neighborhood communication. This is not an official exhaustive topic list.

## QA gates

A publishable item must pass schema/integrity checks, single-best-answer review, Japanese naturalness review, level/Can-do alignment, practical-context review, distractor plausibility, source/bank/batch duplicate checks, provenance completeness, and asset/audio validation where applicable. Numeric thresholds in code are internal operating thresholds, not Japan Foundation standards.

## Practice result interpretation

Until a defensible calibration study exists, report raw correct count and percentage only. Do not derive A1/A2.1/A2.2 from raw accuracy by reusing official scaled-score cut points. Any future estimated practice band must document its mapping, validation data, confidence, and disclaimer here before release.
